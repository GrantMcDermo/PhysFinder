# PhysFinder

This is a project I'm doing mostly for me, but also to showcase my own expertise and possibly build off of it. The goal is to create a character builder for a role-playing campaign based on Pathfinder Second Edition rules that will not only display the relevant stats but also use them to make calculations and guesstimates based on what that character would look like in real life.

An example would be to take a basic human fighter. Depending on what attributes this character has invested in (mainly Strength, Dexterity, or Constitution), we may discern things about their build, and an estimation of height and weight. For other ancestries, some adjustments to calculations may be required.
